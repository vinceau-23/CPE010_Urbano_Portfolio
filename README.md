# CPE010_Urbano_Portfolio

This portfolio contains all the hands on activities and learnings that I have accomplished in while studying CPE-010. 

The course aims to provide an understanding of analyzing algorithms and their complexity. It also allows the development of data structures including Abstract Data types, Linked Lists, Stacks, Queues, Trees, and Graphs using the C+ programming anguage. Additionally, use mathematical techniques to analyze the efficiency of the various algorithms presented, as well as the common operations on the data structures discussed. The course also allows students to implement algorithms and conduct real-system performance measurements and analyses using the C++ programming language. This course aims to contribute towards the attainment of SDG 9 – Industry, Innovation, and Infrastructure.

Course Outcomes
1. Apply fundamental data structures and techniques to solve engineering-related problems through algorithm design.

2. Design efficient algorithms and analyze their complexity 

3. Build efficient algorithms based on selected data structures using good programming styles in C++.

Course Topics:
Prelim Period:
I. Course Introduction: TIP Vision and Mission; TIP Graduate Attributes/Institutional Learning Outcomes; Program Educational Objectives / Student Outcomes; Course Syllabus and Course Requirements; Orientation for Industry and Laboratory Software and Tools.

II. Introduction to Data Structures and Algorithm Analysis: C++ Programming Review, Abstract Data Types, Space and Time Complexity, Algorithm Analysis Techniques.

III. Arrays and Linked Lists: Dynamic Memory Allocation, and Singly, Doubly and Circular Linked Lists

IV. Stacks: Stack using Array, Stack using Linked Lists, Implementation in C++, Problem Solving

Midterm Period:

I. Queues: Queues using Arrays, Queues using Linked Lists, Implementation in C++, Problem Solving

II. Searching Techniques: Linear Search, Binary Search, Hashing

III. Sorting Algorithms: Basic Sorting Algorithms

Final Period:
I. Tree ADT; General and Binary Search Trees; AVL Tree; Traversal Algorithms; Solving Problems using Trees.

II. Graph ADT; Adjacency Matrix and Adjacency List; Breadth-First Search; Depth-First Search; Solving Problems using Graphs.

III. Basic Algorithm Analysis; Theoretical and Experimental Methods in Measuring Time; Time Complexity Classes.
